# Analysis artifacts

All files in this directory are generated outputs tied to the source path, SHA-256, and HEAD recorded in `MANIFEST.json`. They are evidence for that exact run, not a permanent development baseline.

The generic source and UI reports are regenerated by the current workflow. Historical minified-symbol indexes and contexts are legacy hints only; the workflow regenerates them only when `include_legacy_mobile_targets=true` is explicitly selected. Verify all such symbols against the currently selected source before use.

When the source changes, use the newest successful manifest and artifacts for that source. Never reuse a prior source filename, hash, function map, or branch as an automatic baseline.
