# Legacy mobile target contexts

The files in this directory were generated by the former minified-symbol targeting pipeline against the exact source recorded in the adjacent `analysis_parts/MANIFEST.json`. They are historical evidence only, not a current source map or default patch target.

The current analysis workflow does not regenerate these files by default. To regenerate them intentionally, dispatch the workflow with `include_legacy_mobile_targets=true`, then verify every symbol against the selected source.

Do not infer replacement symbols from missing entries, and do not use these historical outputs as the baseline for a new task.
